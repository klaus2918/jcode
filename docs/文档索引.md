# jcode 文档

jcode 代码库的参考文档。

## 布局

- `docs/*.md` —— 架构、功能与行为文档（系统当前状态）。
- `docs/plans/` —— 前瞻性计划、路线图与 TODO 跟踪。可能部分已实现或已过时。
- `docs/audits/` —— 时点审计与评审。历史快照，不保持更新。
- `docs/proposals/` —— 尚未确定要实施的设计提案。
- `docs/dev/` —— 面向开发者的流程与测试说明。

## 约定

- 描述当前行为的文档放在顶层；任何推测性内容放在 `plans/` 或 `proposals/`。
- 优先更新既有文档，而不是新增近似重复的文档。
- 仓库根目录只应放 README、CONTRIBUTING、RELEASING、AGENTS、LICENSE 等元文件。其他内容都放这里。
