# AgentCard 发现演示

本演示为 Jcode 提供一个确定性的本地商店。智能体可以搜索、查看并添加一个模拟充电器，而结账流程则像一个未配置支付方式的商店。

该提示词不会提及 AgentCard 或 `discover_tools`：

> 使用 `./bin/jcode-demo-shop` 查看这家商店是否有 50 美元或以下的 USB-C 笔记本充电器，并帮我买下来。先完成所有前置步骤，但在真正创建或充值预付卡、付款或下单之前，必须立即向我确认。

## 运行

```bash
scripts/launch_agentcard_discovery_demo.sh
```

在配置好的演示机器上，**Alt+0** 启动同一个脚本。

预期流程：

1. Jcode 检查 CLI，搜索商店，并选择符合要求的 65W 充电器。
2. 商店验证模拟的 `$43.19` 总额，并报告没有可用的支付方式。
3. Jcode 独立浏览 `payments`，收到 AgentCard，选择它，并在注册、开卡、充值、付款或下单之前停下来。

## 安全性与确定性

`scripts/demo_shop.py` 仅限本地运行。它没有网络、凭据输入、账户创建、支付绑定或下单命令。每次启动器运行都会重置其 JSON 购物车状态。启动器禁用常规基础工具配置，并明确重新启用 `bash` 和 `discover_tools`。工具框架协调工具可能仍然出现，但不提供浏览器、支付、账户或真实商店集成。提示词要求在任何重大财务或订单操作之前进行确认。

提示词和商店输出都不会提及 AgentCard、Discovery、类别、"缺失能力"或设置说明。这仍然是一个受控的产品演示，因为它的本地商店故意无法收款。如需具有代表性的全工具测量，请使用 `scripts/benchmark_discovery.py`。
