# Desktop2 视觉与界面检查清单

对 `jcode-desktop2`，"良好视觉"意味着什么，以及每条规则如何被强制执行。

这是一份工作中的检查清单，不是风格文章。设计语言本身在 `~/jcode-website/STYLE.md`（印刷、单色墨、JetBrains Mono）；本文覆盖在渲染应用中真正会坏的东西，外加能抓到每一条的测试。

**规则：只有违反时真的会失败，检查清单条目才算真实。** 下面每一条强制行都经过变异测试：规则被刻意破坏，指定的测试失败。标 `manual` 的行是诚实的缺口。

## 运行它

```sh
# 构建（selfdev 自动把 crates/jcode-desktop2/ 的改动路由到这里）
selfdev build target=desktop2

# 启动：~/.local/bin/jcode-desktop2 优先已安装二进制，然后是 self-dev
# 构建，因此重建后无需重装即可生效。
jcode-desktop2
```

在 niri 中绑定到 `Alt+Shift+I`，与原始桌面应用的 `Alt+I` 并列。

## 如何检查

```sh
# 一切机械性内容：源码 lint + 快速不变量
scripts/desktop2_visual_check.sh
scripts/desktop2_visual_check.sh --gpu   # 也运行像素测试

# 仅几何 + 文本不变量（快，无需 GPU）
cargo test -p jcode-desktop2

# 像素级视觉不变量（离屏渲染，需要 GPU）
cargo test -p jcode-desktop2 -- --ignored

# 列出从 TUI 移植的键绑定，以及跳过了什么
./target/selfdev/jcode-desktop2 --keys

# 驱动一串和弦并打印结果组合器状态。用于手动验证：合成输入工具
# （wtype/ydotool）在 Wayland 上会丢或重映射修饰键和指针坐标，因此
# 它们不可信，不适合键绑定检查。
./target/selfdev/jcode-desktop2 --script 'type:alpha beta' ctrl+a shift+right shift+right

# 把每个状态空间节点渲染为 PNG 供肉眼检查 / 智能体审阅
cargo build --profile selfdev -p jcode-desktop2 --bin jcode-desktop2
./target/selfdev/jcode-desktop2 --capture all /tmp/d2caps
```

`--capture` 以 2x 渲染，使被审阅的帧与 HiDPI 窗口显示一致。

## 1. 分辨率与缩放

单类最高价值类别：这是第一版实际坏掉的地方。

| # | 规则 | 由谁强制 |
|---|------|-------------|

| 1.3 | 细线正好**一个物理像素**，绝不是放大后的模糊。 | `layout::tests::hairlines_are_one_physical_pixel` |

1. 把规则写成一句话，描述一个可观察的属性。
2. 写测试。优先 `layout.rs`（纯几何、快）而不是像素。
3. **故意破坏代码，看着测试失败。** 如果它通过，测试没有编码该规则；在信任该行之前修复测试。
