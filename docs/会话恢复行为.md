# `/resume` 行为

`/resume`、`/session` 和 `/sessions` 打开交互式会话选择器。它们是本地 UI 命令，不能作为聊天提示词发送。

## 默认操作

- `Enter` 在当前终端恢复高亮显示的会话。
- `Ctrl+Enter` 在新终端中打开高亮显示的会话。
- `Esc`、`q` 或 `Ctrl+C` 关闭选择器且不切换会话。

默认行为由以下配置控制：

```toml
[keybindings]
session_picker_enter = "current-terminal"
```

将 `session_picker_enter = "new-terminal"` 可交换 `Enter` 和 `Ctrl+Enter` 的行为。

## 当前终端恢复

在当前终端恢复时：

- Jcode 会话会将当前工作区/客户端切换到该会话。
- 可导入的外部会话先转换为 Jcode 会话，然后就地恢复。
- 如果选中了多个会话，只就地恢复第一个选中的目标，UI 会告知用户这一点。
- 排队就地恢复后，选择器关闭。

## 新终端恢复

在新终端中打开时：

- 每个选中的目标尽可能在自己的终端中打开。
- 如果无法启动终端，UI 会打印手动 `jcode --resume <id>` 命令。
- 启动后选择器保持打开，并清除当前多选状态，以便继续打开更多会话。

## 已保存会话

`/save [label]` 将当前会话加入书签，使其出现在选择器的已保存部分。`/unsave` 移除该书签。
